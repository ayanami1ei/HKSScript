# HKS执行引擎

### 一、基本布局
执行引擎包含4层，自底向上分别为：
- [算法层](#alorigthm)
- [特征层](#features)
- [分析层](#query)
- [输出层](#output)

<a id="alorigthm"></a>
### 1、算法层
该层需要封装C++、opencv等基本算法库，同时将算法结果封装成C#对象。需要注意算法应只返回最基础的结果，而不是被处理后的结果，如需要找圆，应该返回圆的位置、半径。

<a id="features"></a>
### 2、特征层
该层需要处理对结果的操作，如需要圆的面积，应该使用一个AreaFeature，输入圆，输出面积

<a id="query"></a>
### 3、分析层
该层需要使用特征层的结果做逻辑判断，从而得到需要的数据，如需要面积大于2的圆，需要对算法的原始输出做面积特征，根据面积大于2的条件过滤

<a id="output"></a>
### 4、输出层
该层负责将结果以各种形式输出，包括但不限于打印、输出到文件、画在图上等

### 二、自定义系统
所有的算法、特征、输出都使用哈希表注册器，基本的保持在注册器内，用户想增加也可以自己增加，代码里使用字符串寻找即可。执行引擎启动时从配置文件读取，增加的功能可以是hks代码，也可以是别的语言的代码
