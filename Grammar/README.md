# HKS脚本语法

### 一、语法规则
&emsp; &emsp; 大部分语句无需写分号
1. 赋值语句<br>
使用let关键字表示赋值，类型由编译器自动推导
```
    let a = 1 //自动推导为整数类型
```

2. query语句<br>
所有可以表示某些数据的集合的对象都可以使用query方法，用于表示从这些对象里筛选出一部分符合条件的
```
    let res = circles.query condition //res类型为圆的集合，仅包含符合condition的圆
```

3. 函数
函数是一类特殊表达式，可以连续计算多个简单的表达式，可以赋给变量，调用时直接写参数即可，声明时需写上参数列表，语句结尾必须加分号;，最后一段表达式为该函数的返回值。
```
    let fn a b = 
                b = a + b
                b + 1; //声明

    let res = fn 1 2 //res为4

```

### 二、库
脚本自带一些基本的函数和算法

1. load string<br>
从第一个参数表示的路径里加载文件
2. save Mat string<br>
把图像保存到指定路径
3. print string<br>
打印到终端
4. println string<br>
打印到终端并换行
5. sql string string<br>
第一个参数表示连接到数据库的命令，第二个参数是sql语句

### 三、编译过程
一下是绝大部分编译器或解释器的前端的基本过程，C#有很多很成熟的库可以通过配置文件完成1、2步

1. 划token<br>
将原代码文本划为标识符、关键字、符号、数字字面量、字符串字面量等类型的token，保留位置信息以便纠错<br>
这部分直接用一个循环依次判断即可，或者使用正则表达式，但是不得直接用不可见的字符划分
2. 构建语法树<br>
将token按语法规则搭建语法树，按token类型检查语法，如let后必定跟着标识符，则遇到let的token时检查下一个是不是标识符
3. 类型推导和报错<br>
所有变量都是从已知的变量经过表达式得到的，既然已知变量的类型已知，表达式的运算过程已知，则可以推出变量的类型。<br>
若一个变量在不同地方有不同类型，或遇到未定义的标识符，则报错<br>
这一步需要构建符号表
4. 生成中间表示（IR）<br>
这是生成其他语言的代码的必须步骤，IR只表示语义，剔除语法，可以当作虚拟指令集。遍历语法树，根据语法树节点生成即可
```
举个例子，C#使用引用语义，变量是对象的指针，变量赋值在语法上是变量=变量，语义上是指针=指针
```
5. IR使用<br>
IR既可以被执行引擎直接解释执行，也可以逆向成别的语言
